🌐 Como atualizar o painel
1

Receba os arquivos do Claude

A cada entrega: index.html + dados.json + .xlsx

2

Abra o repositório no GitHub

github.com/prosys-web/severo-pessoal → Add file → Upload files

3

Suba os 2 arquivos

Selecione index.html e dados.json juntos → Commit changes

4

Aguarde 1-2 minutos

GitHub Pages propaga automaticamente. Atualize a página e pronto.

💡 Dica: Os dados estão embutidos no index.html — o painel sempre funciona, mesmo sem internet. O dados.json é usado como referência futura.
