🌐 Configuração GitHub (uma vez só)
1

Crie o repositório

github.com → New repository → nome: painel-financeiro → pode ser Private → Create

2

Suba os 2 arquivos

Upload index.html e dados.json → Commit changes

3

Ative o GitHub Pages

Settings → Pages → Source: main → Save. Link disponível em ~1 min

4

Salve o link

No celular: Compartilhar → Adicionar à tela de início. Funciona como app.

🔄 Rotina de atualização:
Só o dados.json precisa ser substituído a cada dia. O index.html é fixo — só troque quando Claude entregar melhorias.

📊 Entendendo os números
Entradas Reais — clientes, ajuda familiar, devoluções. Transferências entre suas contas não contam.

Despesas Reais — comércio, família, serviços. Transferências internas não contam.

Saldo Líquido — Entradas menos Despesas. Resultado real do mês.

Outros. (com ponto) — pendentes de classificação. Revise periodicamente.
