🏗 Modelo PIF para Consultoria
1

Cada cliente = 1 repositório

Ex: cliente-arilub → arilub.github.io/painel

2

HTML fixo por cliente

Categorias e contas personalizadas. Nunca muda após configurado.

3

Script publica via API GitHub. Cliente não precisa acessar o repositório.

4

Painel sempre atualizado

Cliente acessa o link e vê os dados do período atual.
